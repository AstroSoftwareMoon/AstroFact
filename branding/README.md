# Identidad visual de AstroFact

Logo en **blanco y negro**: la luna de la familia Astro con un check que la atraviesa
(factura validada). Diseñado en una rejilla de 64 px y probado a 16 px.

| Archivo | Uso |
|---|---|
| `mark.svg` | Glifo (`currentColor`), para UI |
| `icon-black-on-white.svg` / `icon-white-on-black.svg` | Icono cuadrado |
| `logo-black-on-white.svg` / `logo-white-on-black.svg` | Logotipo con nombre |
| `favicon.svg` | Favicon (se adapta a tema claro/oscuro) |
| `android/` | Icono adaptativo Android 8+ (fondo, primer plano y monocromo) |
| `png/` | PNG 16–1024 px; `icon-1024.png` es la fuente para `tauri icon` (fase 4) |
